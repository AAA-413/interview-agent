# Python 异步编程指南

## 什么是异步编程？

异步编程是一种编程范式，允许程序在等待某些操作完成时继续执行其他任务。在 Python 中，异步编程主要通过 asyncio 库实现。

## asyncio 基础

asyncio 是 Python 的标准库，用于编写并发代码。它使用 async/await 语法。

### 基本概念

1. **协程（Coroutine）**：使用 async def 定义的函数
2. **事件循环（Event Loop）**：管理和调度协程的执行
3. **任务（Task）**：对协程的封装，可以并发执行

### 示例代码

```python
import asyncio

async def fetch_data():
    print("开始获取数据...")
    await asyncio.sleep(2)
    print("数据获取完成")
    return {"data": "example"}

async def main():
    result = await fetch_data()
    print(f"结果: {result}")

asyncio.run(main())
```

## 并发执行

使用 asyncio.gather() 可以并发执行多个协程：

```python
async def task1():
    await asyncio.sleep(1)
    return "Task 1 完成"

async def task2():
    await asyncio.sleep(2)
    return "Task 2 完成"

async def main():
    results = await asyncio.gather(task1(), task2())
    print(results)
```

## 最佳实践

1. 使用 async/await 而不是回调
2. 避免在协程中使用阻塞操作
3. 使用 asyncio.create_task() 创建后台任务
4. 正确处理异常和超时

## 常见错误

- 忘记使用 await 关键字
- 在同步代码中调用异步函数
- 事件循环嵌套问题

## 总结

异步编程可以显著提高 I/O 密集型应用的性能。掌握 asyncio 是现代 Python 开发的重要技能。
