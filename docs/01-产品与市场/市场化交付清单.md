# OfferPilot 市场化交付清单

## 目标用户

- **个人求职者**：需要简历改稿、项目表达训练和目标岗位模拟面试。
- **高校就业中心**：需要为学生提供可规模化、可复盘的就业训练工具。
- **培训机构**：需要把学员服务标准化，沉淀训练报告和薄弱点画像。
- **企业内推与招聘辅导**：需要围绕具体岗位做面试预演和候选人准备度评估。

## 首版卖点

1. 简历上传后自动生成多维评分、优势、风险点和改进建议。
2. 支持目标岗位、目标公司和 JD 输入，生成面试准备诊断。
3. 项目深挖围绕真实性、技术深度、表达和延展问题进行训练。
4. 模拟面试支持多方向题库、追问、语音转写和报告导出。
5. 知识库与 GraphRAG 支持把岗位资料、技术文档和个人项目沉淀成训练材料。

## 可售卖包装

| 套餐 | 目标客户 | 包含能力 | 交付口径 |
| --- | --- | --- | --- |
| 个人版 | 求职者 | 简历诊断、模拟面试、报告导出 | 按月订阅或单次报告 |
| 训练营版 | 高校/机构 | 批量账号、题库方向、知识库、复盘报告 | 按班级/批次交付 |
| 专项版 | 机构/企业 | 定制岗位、定制知识库、项目深挖 | 按岗位或项目交付 |

## 演示脚本

1. 进入登录页，注册一个新账号。
2. 进入工作台，说明完整训练闭环和当前资产状态。
3. 上传一份简历，展示分析状态和简历评分。
4. 选择目标岗位，生成面试诊断。
5. 从诊断结果进入项目深挖，展示追问和训练任务。
6. 开始模拟面试，提交回答后展示评分报告。

## 下一批产品化优先级

### 2026-05-22 项目分析结论

当前项目已经进入“能不能让陌生用户稳定试用、愿意付费、出了问题能运营”的阶段。核心能力不是短板，下一步应优先补产品化、商业闭环和运维可信度。

#### P0：近期优先做

1. **教练式反馈增强**：把评分报告升级为可执行训练建议，结构化输出面试官判断、回答问题、推荐框架、80 分回答、90 分回答和下一题。
2. **E2E 测试补齐**：覆盖健康检查、注册登录、认证拒绝、列表接口、诊断接口、输入校验和数据隔离，形成可重复的演示前验收脚本。
3. **配置检查前置**：启动时检查数据库、Redis、AI Key、Embedding Key、CORS、存储配置，提前给出可读错误或告警，减少演示现场踩坑。
4. **样例数据与一键演示**：内置样例简历、样例 JD、样例知识库和样例报告，降低销售演示准备成本。

#### P1：产品商业化

1. 增加组织/团队空间，支持机构按学员管理。
2. 增加付费套餐、用量额度和订单状态。
3. 增加管理员视图：学员训练进度、薄弱点排行、报告下载。
4. 强化 PDF 报告产品化：简历诊断、项目深挖、模拟面试、7 天训练计划。
5. 增加埋点与转化漏斗：注册、上传简历、完成诊断、完成面试、导出报告。

#### P2：规模化运营

1. 岗位与公司模板库：岗位模板、公司风格、难度档位和高频题库。
2. 弱点画像与错题复训：低分题自动进入错题本，生成每日复训任务。
3. 后台任务管理：上传、解析、索引、评估任务可视化和失败重试。
4. 组织级报表：班级/学员训练进度、薄弱点排行、报告批量导出。
