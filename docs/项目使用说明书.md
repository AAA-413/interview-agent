# OfferPilot 项目使用说明书

## 1. 项目简介

OfferPilot 是一个 AI 面试训练工作台，核心流程是：

上传简历 -> 简历分析 -> 面试诊断 -> 项目打磨 -> 模拟面试 -> 复盘报告 -> 训练计划。

当前项目支持：

- 用户注册、登录和多用户数据隔离。
- 简历上传、解析、AI 评分和 PDF 导出。
- 面试诊断和项目打磨。
- 静态模拟面试。
- 动态教练模式：给提示、支持同题重答。
- 动态严厉模式：不给提示，连续追问。
- 知识库上传、索引、RAG 问答和知识图谱。
- 语音输入转文字。

## 3. 环境准备

本地需要：

- Docker Desktop
- Python 3.11
- Node.js
- npm

项目根目录：

```bash
/Users/wacai/Documents/简历智能助手/interview-agent
```

首次配置环境变量：

```bash
cp .env.example .env
```

然后在 `.env` 里填入可用的 LLM API Key，例如 DashScope、智谱 Embedding、Tavily 等。没有真实 Key 时，部分 AI 生成、评估、搜索能力会失败或走降级逻辑。

## 4. 一键启动

推荐在项目根目录执行：

```bash
./start.sh
```

这个命令会启动：

- PostgreSQL + pgvector
- Redis
- MinIO
- FastAPI 后端
- Vite 前端

如果 Docker 依赖已经在运行，只想重启前后端：

```bash
./start.sh --no-infra
```

停止项目：

```bash
./stop.sh
```

## 5. 手动启动方式

后端：

```bash
source .venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 8002 --reload
```

前端：

```bash
cd frontend
npm install
VITE_API_PROXY_TARGET=http://127.0.0.1:8002 npm run dev -- --host 0.0.0.0 --port 5176
```

数据库迁移：

```bash
PYTHONPATH=. .venv/bin/alembic upgrade head
```

## 6. 基础使用流程

### 6.1 注册或登录

打开：

```text
http://127.0.0.1:5176/login
```

可以直接注册新账号。注册完成后会自动登录并进入工作台。

### 6.2 上传简历

入口：

```text
简历管理 -> 上传简历
```

支持格式：

- PDF
- DOCX
- DOC
- TXT

上传后会进入异步分析流程。分析完成后，简历列表会显示分数和状态。

### 6.3 面试诊断

入口：

```text
面试诊断
```

建议填写：

- 目标岗位
- 经验阶段
- 目标公司，可选
- 岗位 JD，可选但推荐
- 已分析完成的简历

诊断会输出：

- 准备度分数
- 关键薄弱项
- 知识缺口
- 今日训练任务
- 7 天训练计划
- 简历追问风险

### 6.4 项目打磨

入口：

```text
项目打磨
```

项目打磨会从简历项目中选择一个重点项目，生成项目讲法草稿、能力证据点、待补素材和追问风险清单。适合先把一个核心项目整理到能讲清、能证明、能被追问，再进入完整模拟面试。

### 6.5 开始模拟面试

入口：

```text
开始面试
```

可以选择：

- 简历，可选
- 面试方向
- 面试模式
- 难度
- 目标岗位
- JD

面试模式说明：

- 模拟面试：一次生成固定题单，适合完整自测。
- 教练模式：每个 topic 回答后给训练提示，可以同题重答。
- 严厉模式：不给提示，像真实面试一样连续追问。

### 6.6 面试记录

入口：

```text
面试记录
```

可以查看历史面试。动态面试未完成时，可以点击“继续面试”回到当前会话。

### 6.7 知识库

入口：

```text
知识库
```

支持：

- 上传本地文件构建知识库。
- 从 URL 抓取文档。
- 等待索引完成后进行 RAG 问答。
- 查看知识库详情、分块和历史问答。

### 6.8 知识图谱

入口：

```text
知识图谱
```

知识图谱会基于知识库抽取实体关系，用于查看技术概念、工具、框架之间的关联。

## 7. 推荐演示路径

一条适合产品演示的路径：

1. 注册一个新账号。
2. 上传一份真实简历。
3. 等待简历分析完成，查看简历评分。
4. 进入面试诊断，填写目标岗位和 JD。
5. 进入项目打磨，查看讲法草稿、质量判断和追问风险。
6. 进入开始面试，选择教练模式，提交一轮回答。
7. 再进入开始面试，选择严厉模式，体验连续追问。
8. 打开面试记录，继续未完成的动态面试。
9. 上传一个知识库文档，测试 RAG 问答。

## 9. 常见问题

### 9.1 前端能打开，但接口报错

先确认后端健康检查：

```bash
curl http://127.0.0.1:8002/api/health
```

再确认前端启动时有代理到后端：

```bash
VITE_API_PROXY_TARGET=http://127.0.0.1:8002
```

### 9.2 简历一直在分析中

确认 Redis、PostgreSQL 和后端 worker 都在运行：

```bash
docker ps
tail -f logs/backend.log
```

如果后台 worker 没启动，重启后端：

```bash
./start.sh --no-infra
```

### 9.3 面试生成失败

优先检查：

- `.env` 里的 LLM API Key 是否有效。
- 后端日志是否出现 LLM 调用失败。
- 当前网络是否能访问模型服务。

日志：

```bash
tail -f logs/backend.log
```

### 9.4 端口被占用

默认端口：

- 后端：`8002`
- 前端：`5176`
- PostgreSQL：`5432`
- Redis：`6379`
- MinIO：`9000` / `9001`

查看占用：

```bash
lsof -nP -iTCP:8002 -sTCP:LISTEN
lsof -nP -iTCP:5176 -sTCP:LISTEN
```

### 9.5 数据库结构不是最新

执行迁移：

```bash
PYTHONPATH=. .venv/bin/alembic upgrade head
```

检查当前版本：

```bash
PYTHONPATH=. .venv/bin/alembic current
```
