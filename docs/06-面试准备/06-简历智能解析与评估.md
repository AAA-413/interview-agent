# 简历智能解析与评估 — 面试技术细节

## 一、整体流程

```
用户上传简历（PDF/DOCX/TXT/MD）
  ↓
文件验证（大小、类型、哈希去重）
  ↓
文档解析（PyMuPDF PDF / python-docx DOCX / 纯文本）
  ↓
MinIO 对象存储（原始文件）
  ↓
XADD Redis Stream（异步分析任务）
  ↓ 立即返回简历ID（<200ms）

StreamWorker 消费
  ↓
LLM 结构化分析（5维度评分 + 简历画像提取）
  ↓
保存分析结果到 DB
```

## 二、文件上传与解析

**代码位置**: `app/modules/resume/upload_service.py`

**支持格式**:
- PDF: PyMuPDF (fitz) 提取文本
- DOCX: python-docx 解析段落
- TXT/MD: 直接读取

**文件验证**:
- 大小限制（通过 FastAPI UploadFile）
- 类型检查
- SHA-256 哈希去重（相同文件不重复存储）

**存储**: MinIO/S3 对象存储，原始文件保留用于后续下载。

## 三、AI 分析（5维度评分）

**代码位置**: `app/modules/resume/grading_service.py`

**结构化输出**:
```python
class _AnalysisDTO(BaseModel):
    overallScore: int  # 总分
    scoreDetail: _ScoreDetailDTO  # 5维度评分
    summary: str  # 整体评价
    strengths: list[str]  # 优势
    suggestions: list[_SuggestionDTO]  # 改进建议
    profile: _ResumeProfileDTO  # 简历画像


class _ScoreDetailDTO(BaseModel):
    projectScore: int  # 项目经验评分
    skillMatchScore: int  # 技能匹配评分
    contentScore: int  # 内容质量评分
    structureScore: int  # 结构清晰度评分
    expressionScore: int  # 表达能力评分
```

**简历画像提取**:
```python
class _ResumeProfileDTO(BaseModel):
    projects: list[_ProjectInfoDTO]  # 项目列表（名称、角色、技术栈、描述、亮点）
    techStacks: list[_TechStackDTO]  # 技术栈（名称、熟练度、使用场景）
    experienceLevel: str  # 经验等级
    hasProjects: bool  # 是否有项目经验
    summary: str  # 画像摘要
```

**面试话术**: 简历分析不只是打分，还提取了结构化的简历画像（项目列表、技术栈、经验等级）。这些信息后续被模拟面试模块复用——出题时基于简历内容生成个性化问题，评估时作为项目题的上下文。

## 四、异步任务处理

**代码位置**: `app/modules/resume/async_tasks.py`

```python
class AnalyzeStreamProducer(StreamTaskProducer):
    async def send_analyze_task(self, resume_id: int) -> None:
        await self.send_task({FIELD_RESUME_ID: str(resume_id)})


class ResumeAnalyzeTaskHandler(StreamTaskHandler):
    async def process(self, db: AsyncSession, key_value: str) -> None:
        entity = await resume_persistence_service.find_by_id_or_throw(db, resume_id)
        await resume_persistence_service.clear_analyses(db, resume_id)
        result = await resume_grading_service.analyze_resume(chat_model, entity.resume_text)
        await resume_persistence_service.save_analysis(db, resume_id, result)
```

## 五、面试常见追问

**Q: 为什么用异步而不是同步分析？**
A: 简历分析需要调用 LLM，耗时 10-30 秒。同步处理会让用户等待过久，体验差。异步化后接口 200ms 内返回，用户可以在列表页看到"分析中"状态，分析完成后自动刷新。

**Q: 如何保证分析结果和简历的一致性？**
A: 上传时先保存简历实体（状态=PENDING），再发送异步任务。分析结果通过 `resume_id` 关联。如果分析失败，状态更新为 FAILED + 记录错误信息，用户可以点击"重新分析"。

**Q: PDF 解析有什么坑？**
A: PyMuPDF 对扫描版 PDF（纯图片）无法提取文本，需要 OCR。当前方案对这种情况会返回空文本，分析时会报错"简历文本为空"。可以后续接入 PaddleOCR 做 OCR 增强。

**Q: 5维度评分的依据是什么？**
A: 通过 System Prompt 定义评分标准，LLM 根据简历内容逐维度打分。例如"项目经验"维度考察是否有真实项目、技术栈是否匹配、成果是否量化等。评分标准定义在 `prompts/resume-analysis-system.md` 中。
