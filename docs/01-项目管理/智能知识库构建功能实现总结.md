# 智能知识库构建功能实现总结

## 功能概述

实现了**用户输入提示词 → Agent 自动识别意图 → 调用 MCP 服务 → 下载资料到知识库**的完整流程。

---

## 核心组件

### 1. KnowledgeBuilderAgent

**文件**: `app/modules/agent_orchestration/agents/knowledge_builder_agent.py`

**功能**:
- 意图识别：使用 LLM 分析用户想要什么资料
- 策略规划：使用 LLM 生成下载计划
- 执行下载：调用 MCP 服务获取资料
- 知识库集成：自动添加到知识库

**执行流程**:
```
用户输入 → 意图识别 → 规划策略 → 执行下载 → 添加到知识库
```

### 2. MCPService

**文件**: `app/common/mcp/mcp_service.py`

**功能**:
- `fetch_url(url)` - 抓取网页内容
- `search_web(query)` - 搜索网页
- `fetch_github(repo, path)` - 获取 GitHub 仓库
- `fetch_arxiv(query)` - 搜索 arXiv 论文

**扩展性**: 可轻松添加更多资源获取能力

### 3. API 路由

**文件**: `app/modules/agent_orchestration/router.py`

**端点**: `POST /api/agent/knowledge-builder`

**请求示例**:
```json
{
  "message": "帮我下载 Python 官方文档",
  "kb_id": null  // 不指定则创建新知识库
}
```

**响应示例**:
```json
{
  "success": true,
  "kb_id": 999,
  "kb_name": "Python官方文档",
  "downloaded_files": 3,
  "chunks_count": 30,
  "message": "成功下载 3 个文件，添加 30 个知识片段",
  "intent": {
    "intent_type": "download_docs",
    "target_resources": ["Python官方文档"],
    "keywords": ["Python", "documentation"],
    "source_preference": "official",
    "language": "zh"
  }
}
```

4. **语言适配**: 自动识别中文需求，优先抓取中文文档

## 技术亮点

### 1. Few-shot Learning

使用 5 个示例引导 LLM 进行意图识别和策略规划，显著提高准确率。

### 2. 自适应规划

根据不同意图类型生成不同的下载策略：
- 官方文档 → 直接抓取
- 学习资料 → 搜索 + 抓取
- 学术论文 → arXiv 搜索

### 3. 模块化设计

- **KnowledgeBuilderAgent**: 核心编排逻辑
- **MCPService**: 资源获取能力
- **LLMAdapter**: LLM 调用封装

易于扩展和维护。

### 4. 错误处理

- 单个步骤失败不影响整体流程
- 自动跳过失败的下载
- 详细的日志记录

## 使用方式

### 方式 1: API 调用

```bash
curl -X POST http://localhost:8001/api/agent/knowledge-builder \
  -H "Content-Type: application/json" \
  -d '{
    "message": "帮我下载 React 官方文档",
    "kb_id": null
  }'
```

### 方式 2: Python 代码

```python
from app.modules.agent_orchestration.agents.knowledge_builder_agent import KnowledgeBuilderAgent

agent = KnowledgeBuilderAgent(
    llm_provider=llm_provider,
    mcp_service=mcp_service,
    knowledge_service=knowledge_service,
)

result = await agent.execute(
    user_input="帮我下载 Vue.js 官方文档",
    kb_id=None,
)

print(f"成功: {result.success}")
print(f"知识库ID: {result.data['knowledge_base']['kb_id']}")
print(f"下载文件: {len(result.data['downloaded_files'])} 个")
```

### 方式 3: 前端集成

```typescript
// 调用 API
const response = await fetch('/api/agent/knowledge-builder', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    message: '帮我下载 TypeScript 官方文档',
    kb_id: null
  })
});

const result = await response.json();
console.log(`知识库ID: ${result.kb_id}`);
console.log(`下载文件: ${result.downloaded_files} 个`);
console.log(`知识片段: ${result.chunks_count} 个`);
```
