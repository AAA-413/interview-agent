## 七、常见问题

### Q1: Reranking 模型未安装怎么办？
**A:** 服务会自动降级，跳过重排序步骤，不影响基本功能。
```bash
# 安装 Reranking 依赖
pip install sentence-transformers
```

### Q2: pgvector 扩展安装失败？
**A:** 需要 PostgreSQL 超级用户权限，联系 DBA 安装。
```sql
-- 检查权限
SELECT current_user, usesuper FROM pg_user WHERE usename = current_user;

-- 安装扩展（需要超级用户）
CREATE EXTENSION vector;
```

### Q3: 阿里云 Embedding API 调用失败？
**A:** 服务会自动降级到哈希向量，不影响基本功能。
```bash
# 检查 API Key 是否正确
echo $DASHSCOPE_API_KEY

# 查看日志
tail -f logs/app.log | grep "Embedding"
```
