## 一、项目概况

**智能面试 Agent 平台** - 基于 Python (FastAPI + LangChain) 和 React 的智能面试系统

- **后端**：FastAPI + SQLAlchemy + PostgreSQL + Redis
- **前端**：React 18 + TypeScript + Tailwind CSS 4
- **AI 服务**：阿里云百炼（qwen-plus + text-embedding-v2）
- **向量检索**：当前 JSON 字段，待升级到 pgvector
