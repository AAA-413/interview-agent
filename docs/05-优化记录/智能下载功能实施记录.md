# 智能下载知识库功能实施记录

## 实施时间
- 开始时间：2024-01
- 当前状态：开发中

## 实施背景

### 用户需求
用户在上传知识库模块中提出需求：希望通过自然语言描述需求（如"我想学习FastAPI"），系统能够自动分析并下载相关资料到知识库。

### 核心要求
1. **智能理解**：用户输入需求描述，AI自动识别意图
2. **计划确认**：生成下载计划供用户审核后再执行
3. **多源支持**：支持知名博客网站（CSDN、掘金、知乎、Medium等）和通用网页
4. **实时进度**：显示下载进度和状态
5. **数量限制**：最多下载10个资源
6. **质量保证**：使用4步Agent编排（Planning→Execution→Quality→Summary）
7. **重试机制**：质量检查失败后自动重试，最多3次

## 技术方案

### 架构选型

采用**两阶段流程 + 4步Agent编排**的架构：

```
阶段1：生成计划
用户输入 → PlanningAgent → 生成计划 → 用户确认

阶段2：执行下载
用户确认 → ExecutionAgent → QualityAgent → SummaryAgent → 完成
                ↓ 质量不达标 ↑
                └─── 重试（最多3次）
```

### 技术栈

**后端：**
- FastAPI：异步API框架
- AgentOrchestrator：Agent编排器（已有）
- MCP Service：内容抓取服务（需扩展）
- PostgreSQL + pgvector：知识库存储（已有）

**前端：**
- React + TypeScript
- 实时进度轮询（每2秒）

#### 1.1 创建路由模块

**文件：** `app/modules/agent_orchestration/smart_download_router.py`

**实现内容：**
- 定义3个核心端点：
  - `POST /plan`：生成下载计划
  - `POST /execute`：执行下载计划（后台任务）
  - `GET /progress/{task_id}`：查询下载进度
- 全局状态管理：
  - `_download_plans`：存储生成的计划
  - `_download_tasks`：存储执行进度

**关键代码：**
```python
@router.post("/plan", response_model=DownloadPlan)
async def generate_download_plan(request: PlanDownloadRequest):
    """阶段1：生成下载计划"""
    llm_provider = llm_registry.get_provider("deepseek")
    planning_agent = PlanningAgent(llm_provider=llm_provider)
    result = await planning_agent.execute(user_input=request.user_input)
    # 生成计划并返回

@router.post("/execute")
async def execute_download_plan(
    request: ExecuteDownloadRequest,
    background_tasks: BackgroundTasks
):
    """阶段2：执行下载计划（后台任务）"""
    background_tasks.add_task(_execute_download_task, task_id, plan, request)
    # 返回task_id供前端轮询
```

```python
async def plan_download(self, user_input: str, max_downloads: int) -> Dict[str, Any]:
    # 1. 意图识别
    intent = await self._analyze_intent(user_input)
    
    # 2. 资源搜索
    resources = await self._search_resources(intent, max_downloads)
    
    # 3. 生成步骤
    steps = self._generate_steps(resources)
    
    # 4. 估算信息
    estimated_time = self._estimate_time(steps)
    
    return {
        "intent": intent,
        "steps": steps,
        "estimated_time": estimated_time,
        "total_steps": len(steps)
    }
```

```python
async def execute_step(self, step: DownloadStep, kb_id: int) -> Dict[str, Any]:
    if step.action == "fetch_url":
        result = await mcp_service.fetch_url(step.params["url"])
    elif step.action == "fetch_blog":
        result = await mcp_service.fetch_blog(step.params["url"])
    elif step.action == "search_web":
        result = await mcp_service.search_and_fetch(step.params["query"])
    
    # 保存到知识库
    await knowledge_service.add_document(kb_id, result["content"])
    
    return result
```

```python
async def check_quality(self, downloaded_files: List[Dict], plan: DownloadPlan) -> Dict[str, Any]:
    # 1. 完整性检查
    completeness = len(downloaded_files) / plan.total_steps
    
    # 2. 准确性检查（使用LLM）
    accuracy = await self._check_accuracy(downloaded_files, plan.intent)
    
    # 3. 质量检查
    quality = await self._check_content_quality(downloaded_files)
    
    # 4. 可用性检查
    usability = self._check_usability(downloaded_files)
    
    total_score = (completeness + accuracy + quality + usability) / 4
    
    return {
        "passed": total_score >= 0.7,
        "score": total_score,
        "dimensions": {
            "completeness": completeness,
            "accuracy": accuracy,
            "quality": quality,
            "usability": usability
        }
    }
```

## 技术难点

### 1. 意图识别准确性
**问题：** 用户输入的自然语言描述可能模糊或不准确

**解决方案：**
- 使用LLM进行意图分析
- 提供示例引导用户输入
- 支持交互式澄清

### 2. 资源质量评估
**问题：** 如何判断下载的内容是否符合用户需求

**解决方案：**
- 四维度评分机制
- 使用LLM进行内容相关性判断
- 支持用户反馈和调整

### 3. 反爬虫处理
**问题：** 部分网站有反爬虫机制

**解决方案：**
- 使用合理的请求频率
- 添加User-Agent和Referer
- 必要时使用浏览器自动化（Playwright）

### 4. 实时进度更新
**问题：** 后台任务如何实时更新进度

**解决方案：**
- 使用全局字典存储进度状态
- 前端轮询（每2秒）
- 未来可升级为WebSocket推送

## 风险和应对

### 风险1：下载失败率高
**应对：**
- 实现重试机制（最多3次）
- 记录失败原因供用户查看
- 提供手动重试选项

### 风险2：内容质量不达标
**应对：**
- 质量检查机制
- 自动重试
- 用户可手动删除不满意的内容

### 风险3：性能问题
**应对：**
- 限制并发数量
- 限制单个文件大小
- 异步处理
