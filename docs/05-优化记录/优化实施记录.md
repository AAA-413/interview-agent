def split_text(self, text: str, *, chunk_size: int = 900, overlap: int = 120, doc_type: str = "general"):

### ✅ 8. P1 评估服务并行化

**文件：** `app/modules/interview/evaluation_service.py`

**优化内容：**

1. **批次并行执行**
   - 使用 `asyncio.gather` 并行执行多个批次
   - 使用 `Semaphore` 限制最大并发数为 3
   - 避免过多并发导致 API 限流

2. **异常处理优化**
   - 使用 `return_exceptions=True` 捕获异常
   - 失败的批次返回 None，不影响其他批次
   - 记录详细的错误日志

**代码示例：**
```python
async def _evaluate_in_batches(self, ...):
    semaphore = asyncio.Semaphore(self._max_concurrent_batches)
    
    async def evaluate_with_limit(batch):
        async with semaphore:
            return await self._evaluate_batch(...)
    
    tasks = [evaluate_with_limit(batch) for batch in batches]
    results = await asyncio.gather(*tasks, return_exceptions=True)
```

**预期收益：**
- 评估时间：20-30 秒 → 10-15 秒（减少 50%）
- 用户等待时间显著降低
- 系统吞吐量提升

   - 支持降级：模型未安装时自动禁用

2. **集成到 RAG 服务**
   - 召回阶段：Top-K × 2（获取更多候选）
   - 重排序阶段：Cross-Encoder 精排 → Top-K
   - 自动检测：模型未安装时跳过重排序

3. **模型选择**
   - 默认：bge-reranker-base（~400MB，性能良好）
   - 可选：bge-reranker-large（~1GB，性能最佳）

**代码示例：**
```python
class RerankService:
    def __init__(self, model_name: str = "BAAI/bge-reranker-base"):
        try:
            from sentence_transformers import CrossEncoder
            self.model = CrossEncoder(model_name, max_length=512)
            self._enabled = True
        except ImportError:
            logger.warning("sentence-transformers 未安装，重排序功能已禁用")

    async def rerank(self, query: str, chunks: List[RagReferenceDTO], top_k: int):
        if not self._enabled:
            return chunks[:top_k]
        
        # 构造查询-文档对
        pairs = [(query, chunk.content_preview) for chunk in chunks]
        
        # 计算相关性分数（线程池执行）
        loop = asyncio.get_event_loop()
        scores = await loop.run_in_executor(None, self.model.predict, pairs)
        
        # 按分数排序并返回 Top-K
        scored_chunks = list(zip(chunks, scores))
        scored_chunks.sort(key=lambda x: x[1], reverse=True)
        return [chunk for chunk, _ in scored_chunks[:top_k]]
```

**RAG 服务集成：**
```python
# 召回更多候选（Top-K × 2）
context = SearchContext(top_k=top_k * 2, ...)
candidates = await self.retrieval_engine.retrieve(context)

# 重排序精排（Top-K）
references = await self.rerank_service.rerank(question, candidates, top_k)
```
